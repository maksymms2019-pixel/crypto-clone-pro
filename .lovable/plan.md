# Монетки: доробка фронтенду (гаманець, рівні, рейтинг, розіграші)

База вже готова й застосована: `public_code`, opt-in, лідерборд, зрізи, денний ліміт. Лишається фронтенд.

## 1. Фікс збірки
- `CoinReward.tsx` рядок 122: `haptic("light")` → `haptic("tap")` (валідні значення: tap/success/error). Це блокує білд.

## 2. Нові рівні у `src/lib/coinLevels.ts`
| Рівень | Від | Візуал |
|---|---|---|
| Бронза | 0 | мідний градієнт, матовий блиск |
| Срібло | 25 | холодний метал, м'який відблиск |
| Золото | 75 | золотий градієнт + сяйво |
| Діамант | 150 | крижано-блакитний кристал, мерехтіння |
| Легенда | 300 | вогняний, пульсуюча аура |

Кожен рівень: свій колір пілюлі-лічильника, сяйво, градієнт бейджа, підпис. Прогрес-бар — у кольорі рівня.

## 3. Гаманець `CoinWalletSheet.tsx` — повний редизайн
- **Фікс обрізання зверху:** `max-h: 88dvh`, внутрішній скрол, відступ під safe-area, липкий хедер (баланс + ✕) — кнопка закриття завжди видима.
- **Вкладки:**
  - **Гаманець** — анімований лічильник, бейдж рівня, прогрес до наступного, список усіх рівнів.
  - **Рейтинг** — топ-100 з RPC `coin_leaderboard` (ім'я, код, баланс, місце), виділення свого рядка; перемикач «Брати участь у розіграшах» (`set_leaderboard_opt_in`).
  - **Розіграші** — твій Coin ID (`CT-XXXXXX`) з кнопкою «копіювати»; історія зрізів через `my_snapshot_results` («Розіграш від 21.08: 128 монет, місце 42»).
- Закриття: ✕, тап по фону, Esc, свайп вниз (вже частково є — доповнити).

## 4. `CoinReward.tsx`
- Пілюля-лічильник фарбується в колір рівня (вже частково) + при підвищенні рівня: разова анімація `animate-coin-pop` і тост «Новий рівень: Золото 🥇».
- Обробка нової помилки `daily_limit` з `award_point` → тост «Денний ліміт монеток».

## 5. Джерело даних
- Гаманець читає `my_coin_stats()` (баланс + код + ранг + opt-in одним запитом) замість голого `user_points`; кеш react-query з `staleTime` 60 с, миттєве локальне оновлення після збору монетки.

## 6. Перевірка
- Прогін у браузері (мобільний в'юпорт 390px): відкрити гаманець (верх не обрізаний, скрол працює), вкладки, копіювання Coin ID, перемикач участі, рейтинг.
- Збір монетки → баланс і колір оновились.
- Адмінський зріз через `create_coin_snapshot` → з'явився у вкладці «Розіграші».

## Технічні деталі
- RPC уже в БД: `my_coin_stats`, `coin_leaderboard(int)`, `set_leaderboard_opt_in(bool)`, `my_snapshot_results(int)`, `create_coin_snapshot(text,text)` (admin-only).
- Оновлю `src/integrations/supabase/types.ts` вручну під нові RPC (або каст на місці, якщо типи не генеруються).
- Нові ключі Gemini (`GEMINI_API_KEY_2/3`) — ротація в `ai-assistant` уже в коді; якщо надішлеш ключі — додам у секрети.
