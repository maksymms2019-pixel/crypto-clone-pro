# Живі ціни + компактний «Прогноз дня» з токеном дня

## 1. Ціни (пріоритет)

Що з'ясовано: сервер ринків отримує від CoinGecko відмову (403), і тоді мовчки віддає старі збережені дані. Тому BTC показує ~$77,454 з датою 23.08, хоча реальна ціна зараз ~$83,900. Безкоштовний доступ CoinGecko блокує спільні сервери.

Що зробимо:
- Резервні джерела цін: якщо CoinGecko не відповідає — беремо ціни й зміну за 24г з OKX / Binance (як уже працює у прогнозах) і накладаємо їх на список монет. Ціни будуть свіжими навіть при збоях CoinGecko.
- Підтримка безкоштовного ключа CoinGecko (Demo API) — попрошу вас його додати, це прибирає блокування для графіків, деталей монет і капіталізації.
- Старі дані більше не віддаються «назавжди»: якщо даним більше 30 хв і всі джерела впали — показуємо помітку «дані оновлюються», а не застарілі цифри мовчки.
- Невелика підпис «оновлено щойно / N хв тому» біля цін, щоб одразу було видно актуальність.
- Перевіряю всі розділи, що беруть дані з цього ж сервера: головна (стрічка цін, лідери росту/падіння, трендові), Ринки, Heatmap, сторінка монети, портфель.

## 2. «Прогноз дня»

- Раунди: **BTC** щодня + **токен дня**, що змінюється щодня з топ-10 (без стейблкоінів і BTC), по черзі за датою — однаково для всіх, без повторів два дні поспіль.
- Компактна картка: один рядок-смужка на головній (два міні-блоки: монета, стартова ціна, поточна зміна, % UP/DOWN, таймер). Натискання відкриває нижню шторку з кнопками UP/DOWN, ставкою 20/50/100, результатами та історією. Головний екран знову вміщує всю інформацію без прокрутки.
- Адмін-кнопка скасування раунду з поверненням ставок (у шторці, видно лише адміну).
- Сьогоднішній раунд GRAM дограється до 21:00 як є; новий токен стартує з завтра.

## Технічні деталі

- `markets-proxy`: опційний `COINGECKO_API_KEY` (заголовок `x-cg-demo-api-key`), фолбек для `markets`/`trending`/`gainers_losers` через OKX tickers (`/market/tickers?instType=SPOT`) + Binance `ticker/24hr`, мапа symbol→USDT; ліміт віку stale-кешу 30 хв, у відповіді `updated_at`; для `global` — фолбек CoinPaprika `/v1/global`.
- `predictions-cron`: список топ-10 через CoinGecko/CoinPaprika, фільтр стейблів, вибір за індексом дня; ціна з OKX→Binance за символом. Колонка `asset` уже текстова — міграція лише для збереження `symbol/name/image` раунду (нові nullable колонки) і оновлення `prediction_overview`.
- Фронтенд: `DailyPrediction.tsx` → компактний рядок + `PredictionSheet`; `PriceTicker`/`MarketMetrics` показують час оновлення.
- Перевірка: curl функції (свіжий `last_updated`), Playwright головної в 390×800 без прокрутки, ставка під реальною сесією.
